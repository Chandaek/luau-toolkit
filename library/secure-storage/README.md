# SecureStorage

<p>
A memory-optimized Luau storage module that uses intelligent data tiering to reduce memory overhead by dynamically shifting values between standard Luau tables and binary Luau buffers based on access frequency.
</p>

</div>

This package is implemented but not actively developed. Maintenance only.

# Overview

SecureStorage separates data into multiple storage tiers to optimize both performance and memory efficiency.

| Tier | Description |
|---|---|
| **Hot Tier** | Primitive values stored directly in Luau tables for ultra-fast access. |
| **Cold Tier** | Primitive values serialized into raw binary data using Luau buffers to minimize table overhead. |
| **Pinned Tier** | Complex non-primitive values stored directly in tables because they cannot be serialized natively. |

---

# How It Works

The engine continuously tracks access behavior and dynamically migrates values between tiers.

- Frequently accessed values are promoted into the **Hot Tier**
- Inactive values are flushed into the **Cold Tier**
- Complex structures remain permanently pinned

This allows the system to reduce memory consumption without sacrificing access speed for frequently used data.

# Properties

## `Alive: boolean`

Reflects the current liveness of the storage instance.

Set to `true` on construction. Set to `false` permanently when the instance is destroyed, either by calling `:Destroy()` or by passing `Kill = true` to `:Export()`.

All methods error if called on a dead instance. `Alive` remains readable after death because it is set before the instance is frozen.

```lua
if Storage.Alive then
    Storage:Set("Key", 1)
end
```

# Methods

## `:Set(key: string, value: any): ()`

Inserts or updates a value.

Passing `nil` automatically invokes `:Delete()`.

Primitive values may optionally be serialized directly into the cold buffer depending on configuration.

---

## `:Get(key: string): any`

Retrieves a value from storage.

Cold-tier reads automatically track access metrics. Frequently accessed values are promoted back into the hot tier.

---

## `:Delete(key: string): ()`

Removes a key from storage.

Also cleans internal tracking data and safely marks fragmented regions inside the binary buffer.

---

## `:Has(key: string): boolean`

Performs a fast existence lookup across all storage tiers.

### Returns

| Type | Description |
|---|---|
| `boolean` | Whether the key exists. |

---

## `:Keys(): {string}`

Returns all active keys currently stored inside the engine.

### Returns

| Type | Description |
|---|---|
| `{string}` | Array containing all active keys. |

---

## `:Flush(): ()`

Manually flushes inactive hot-tier values into the cold buffer.

Useful when deterministic memory cleanup is required.

---

## `:Compact(): ()`

Defragments the binary buffer and frees dead memory regions generated by deletions or overwrites.

---

## `:Expand(budget: number?): ()`

Manually expands the internal buffer allocation.

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `budget` | `number?` | Optional expansion size. Falls back to configured allocation increment if omitted. |

---

## `:Stats(): EngineStats`

Returns real-time telemetry about the storage engine.

### Returns

| Type | Description |
|---|---|
| `EngineStats` | Runtime statistics and memory telemetry. |

### Example Output

```lua
{
    HotCount = 120,
    ColdCount = 532,
    PinnedCount = 7,
    BufferUsed = 4096,
    BufferCapacity = 8192,
    FragmentationBytes = 240,
}
```

---

## `:Export(includeConfig: boolean?, kill: boolean?): ({[string]: any}, StorageConfiguration?)`

Exports all stored data as a flat key-value table. Decodes cold-tier values from the binary buffer so the result is a plain Lua table regardless of what tier each value was in.

Optionally returns the original configuration as a second value, containing only the fields that were explicitly set when the instance was constructed — default-filled fields are omitted.

If `kill` is `true`, the instance is permanently destroyed after the export data is captured, setting `Alive` to `false` and clearing all internal state.

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `includeConfig` | `boolean?` | When `true`, returns the explicit-only config as the second return value. |
| `kill` | `boolean?` | When `true`, destroys the instance after export. |

### Returns

| Position | Type | Description |
|---|---|---|
| 1 | `{[string]: any}` | All stored key-value pairs. |
| 2 | `StorageConfiguration?` | Explicit config fields, or `nil` if `includeConfig` was not `true`. |

### Example

```lua
local Data, Config = Storage:Export(true, true)

-- Storage.Alive is now false
-- Data contains every key that was in the storage
-- Config contains only what was passed to .new()
```

---

## `:Destroy(): ()`

Destroys the storage instance permanently.

Sets `Alive` to `false`, clears all memory structures, removes the metatable, and freezes the instance. Safe to call more than once — subsequent calls are silently ignored.

# Configuration

## `StorageConfiguration`

```lua
type StorageConfiguration = {
    DataMigration: boolean?,
    BufferMigrationRequest: number?,
    BufferMigrationResetTime: number?,
    BufferDefaultBudget: number?,
    BufferBudgetAllocation: "Auto" | "Manual"?,
    StoreToBufferOnSet: boolean?,
    TableMigrationTime: number?,
    MaxBudget: number?,
    CompactionThreshold: number?,
    FlushInterval: number?,
    SmartShrink: boolean?,
    ShrinkHeadroom: number?,
}
```

---

# Configuration Fields

| Field | Type | Default | Description |
|---|---|---|---|
| `DataMigration` | `boolean?` | `true` | Enables automatic hot/cold tier migration. |
| `BufferMigrationRequest` | `number?` | `3` | Reads required before cold data is promoted to hot. |
| `BufferMigrationResetTime` | `number?` | `5` | Time window in seconds before read counters reset. |
| `BufferDefaultBudget` | `number?` | `500` | Initial binary buffer allocation size in bytes. |
| `BufferBudgetAllocation` | `"Auto" \| "Manual"?` | `"Manual"` | Controls automatic buffer growth behavior. |
| `StoreToBufferOnSet` | `boolean?` | `false` | Forces primitives into the cold buffer immediately on write. |
| `TableMigrationTime` | `number?` | `30` | Idle duration in seconds before hot values migrate to cold storage. |
| `MaxBudget` | `number?` | `0` | Hard memory allocation cap for the buffer. `0` means no cap. |
| `CompactionThreshold` | `number?` | `0.4` | Fragmentation ratio that triggers automatic compaction. |
| `FlushInterval` | `number?` | `0` | Background flush interval in seconds. `0` disables auto-flush. |
| `SmartShrink` | `boolean?` | `true` | Dynamically shrinks compacted buffer size based on usage. |
| `ShrinkHeadroom` | `number?` | `0.1` | Reserved headroom percentage added during smart shrinking. |

---

# Example

```lua
local SecureStorage = require(path.To.SecureStorage)

local Storage = SecureStorage.new({
    DataMigration = true,
    BufferDefaultBudget = 4096,
    StoreToBufferOnSet = false,
    FlushInterval = 30,
})

Storage:Set("Coins", 150)
Storage:Set("Username", "Chandaek")

print(Storage:Get("Coins"))
print(Storage.Alive) -- true

-- Export everything and shut the instance down
local Data, Config = Storage:Export(true, true)

print(Storage.Alive) -- false
print(Data.Coins)    -- 150
print(Config.BufferDefaultBudget) -- 4096
```
